I'm a B.Tech (CSE - AI) student at Manipal Institute of Technology, currently working as a Software Engineer on Upwork where I build event-driven trading systems and automation tooling. My interests are backend engineering, applied AI/retrieval systems, and building things that have to be correct, not just working.

### What I'm up to

- Building an event-driven NSE intraday trading platform (Python, Zerodha Kite Connect API) with a 5-year backtesting engine, crash recovery and persistent risk controls
- Built a FastAPI knowledge platform with a custom HNSW search implementation from scratch, benchmarked against brute-force search and ChromaDB
- Built an AI PR & Code Review Assistant that analyzes real GitHub PRs with a transparent risk-scoring formula
- Solved 150+ DSA problems on LeetCode
- Earned a 5-Star Gold Badge on HackerRank and Top Rated status on Upwork

## Projects

**[AI PR & Code Review Assistant](https://github.com/ritk7/ai-pr-analyzer)** — MERN tool that connects to GitHub, analyzes real PRs and flags risky changes with AI-generated explanations and a transparent risk-scoring formula. Validated on 5+ real-world repos with 40 automated tests.

**[AI Knowledge & Document Platform](https://github.com/ritk7/AI-Knowledge-Document-Management-Platform)** — FastAPI service for uploading files and getting answers with page-level citations, using hybrid search and a custom HNSW implementation. 0.950 MRR with cross-encoder re-ranking on a 35-question eval set.

**[Predictive Maintenance for Jet Engines](https://github.com/ritk7/predictive-maintenance-ml)** — Predicts jet engine failure from real NASA sensor data across 3 regression models. Found and fixed a critical bug in risk-level assignment, cutting missed failures by 47% with F2-weighted threshold tuning.
